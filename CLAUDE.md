# sami-ascend

Read these first, in order: `specs/constitution.md`, `specs/tech-stack.md`, `specs/roadmap.md`,
`specs/notes.md`.

## Which phase am I working on?
The git branch decides. On `<app>/phase-<nn>-<name>`, read and work only in
`specs/<app>/<nn>-<name>/`. On `main`, no phase is active: ask which phase to work on.
Never edit another phase's folder or files outside the phase's app unless its spec says so.

Hard rules (details in the constitution): small task groups, stop for review before every
commit, no comments in code, simple readable classes, clean architecture layers.
